# Physical AI Robotics Tutorials with OpenVINO™

<img src="https://github.com/openvinotoolkit/physicalai/raw/docs/tutorials/docs/assets/OVPhysicalAIheader.png" width="1000"/>

This directory contains a **reference notebook** that points to the OpenVINO™ Physical AI robotics tutorials. They are developed and maintained in the dedicated [`openvinotoolkit/physicalai`](https://github.com/openvinotoolkit/physicalai) repository and are **not copied here**, so there is a single source of truth and nothing to keep in sync. The notebook [physical-ai-robotics.ipynb](./physical-ai-robotics.ipynb) simply links to the authoritative location.

## Notebook Contents

The tutorials live in the [physicalai](https://github.com/openvinotoolkit/physicalai) repository. The reference notebook points to both published tutorial pages:

- **[Collect → Train → Deploy walkthrough](https://github.com/openvinotoolkit/physicalai/blob/main/examples/tutorials/README.md)** — a single end-to-end tutorial: data collection, visuomotor policy training, OpenVINO optimization, and deployment on a real robot.
- **[Full tutorial notebook collection](https://github.com/openvinotoolkit/physicalai/blob/docs/tutorials/examples/tutorials/README.md)** — a broader set of notebooks: an introduction, using Physical AI Studio, OpenVINO optimization, testing deployment without a robot, and a full data-collection-to-deployment workflow.

## Requirements

The tutorials need Intel® hardware for OpenVINO plus robotics hardware (a robot arm and a camera). The **authoritative, up-to-date requirements and setup steps are documented in the [physicalai](https://github.com/openvinotoolkit/physicalai) repository** — follow them there. For OpenVINO-supported platforms, see the [OpenVINO System Requirements](https://docs.openvino.ai/2026/about-openvino/release-notes-openvino/system-requirements.html).

## Installation Instructions

This is a reference notebook and does not execute any code. The tutorials it links to are hosted in the [physicalai](https://github.com/openvinotoolkit/physicalai) repository and ship with their own installation instructions. To run them, clone that repository and follow the setup steps in each tutorial.
