# Whisper and Distil-Whisper model evaluation

This is a supplementary notebook to the blogpost [Optimizing Whisper and Distil-Whisper for Speech
Recognition with OpenVINO and NNCF](https://blog.openvino.ai/blog-posts/optimizing-whisper-and-distil-whisper-for-speech-recognition-with-openvino-and-nncf). This notebook performs evaluation of Whisper and Distil-Whisper models on [Common Voice 13](https://huggingface.co/datasets/mozilla-foundation/common_voice_13_0). For the current Whisper workflow, see the [Whisper ASR notebook](../../../notebooks/whisper-asr-genai/whisper-asr-genai.ipynb).
